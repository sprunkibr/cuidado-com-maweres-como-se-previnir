Todos os Tipos de Malware

💀 Todos os Tipos de Malware

  • Vírus: Anexa-se a arquivos legítimos para se espalhar.
  • Worm: Autorreproduz e se espalha por rede sem interação humana.
  • Trojan (Cavalo de Tróia): Finge ser útil, mas executa código malicioso.
  • Spyware: Coleta informações sem permissão.
  • Adware: Exibe anúncios indesejados e pode coletar dados.
  • Ransomware: Criptografa arquivos e exige resgate.
  • Rootkit: Se esconde profundamente no sistema para permitir controle remoto.
  • Keylogger: Registra tudo que é digitado no teclado.
  • Backdoor: Cria uma "porta dos fundos" para acesso não autorizado.
  • Bot: Controla o sistema e o conecta a uma botnet.
  • Rogue Security Software: Finge ser antivírus para enganar e extorquir.
  • Fileless Malware: Não usa arquivos no disco; atua diretamente na memória.
  • Cryptojacker: Usa seu PC para minerar criptomoeda sem permissão.
  • Polymorphic Malware: Muda de forma para evitar detecção.
  • Malicious Macro: Ataca usando macros de arquivos Office (Word, Excel).
  • Browser Hijacker: Redireciona seu navegador para sites falsos.
  • Scareware: Assusta o usuário com mensagens falsas de vírus.
  • Logic Bomb: Dispara uma ação maliciosa quando uma condição é cumprida.
  • Firmware Malware: Infecta o firmware do hardware, como BIOS/UEFI.
Modelos Avançados de Malware

🧬 Modelos Avançados

Estes malwares são usados em espionagem digital e guerras cibernéticas:

  • Stuxnet: Criado para sabotar infraestrutura industrial.
  • Flame: Malware altamente sofisticado de espionagem.
  • Duqu: Variante do Stuxnet, usada para coleta de informações.
  • Regin: Espionagem em empresas e governos, com arquitetura modular.
  • DarkHotel: Alvo principal: executivos em hotéis via Wi-Fi.
  • FinFisher: Comercializado para agências de governo com foco em vigilância.
